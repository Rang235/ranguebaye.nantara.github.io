Contexte et problématique

NTIC CENTER CORPORATION (NCC) est une ESN de 15 collaborateurs établie au 52 rue Charles Michels, 93200 Saint-Denis, spécialisée en cybersécurité, cloud computing, infogérance et formation IT.

Au lancement de la mission, NCC ne disposait d'aucune infrastructure réseau structurée : équipements dispersés, accès non centralisés, aucun système de supervision ni de journalisation. Face à l'accueil croissant de stagiaires et à l'expansion de ses activités, la direction a mandaté le déploiement complet d'un SI sécurisé et pédagogique.

Problématique : Comment concevoir et déployer une infrastructure réseau sécurisée, scalable et pédagogique, adaptée aux contraintes d'une PME du secteur numérique ?

Architecture technique

L'infrastructure repose sur un modèle entièrement on-premise virtualisé sous VMware Workstation Pro, hébergé sur un poste physique de 16 Go RAM / 8 cœurs. 10 VMs ont été déployées sur 5 réseaux VMnet distincts (host-only) + 1 VMnet bridgé (WAN).

Étape 2 — Active Directory ncc.local

P2
Forêt ncc.local — Authentification centralisée & Haute Disponibilité
2 semaines — Février 2026

Premier besoin fondamental : sans annuaire, impossible de gérer les accès, GPO et ressources partagées. J'ai déployé une forêt AD en HA avec deux contrôleurs de domaine.

Préparation AD-DC01 — IPv6 et IP statique

PowerShell — AD-DC01 (10.10.10.10, VLAN ADMIN)Windows Server 2022
# Désactivation IPv6 (éviter conflits DNS)
Disable-NetAdapterBinding -Name "Ethernet0" -ComponentID ms_tcpip6

# IP statique
New-NetIPAddress -InterfaceAlias "Ethernet0" `
  -IPAddress 10.10.10.10 -PrefixLength 24 -DefaultGateway 10.10.10.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet0" -ServerAddresses 127.0.0.1

Promotion AD-DC01 — Création de la forêt ncc.local

PowerShell — Installation forêt & rôles FSMOWindows Server 2022
# Installation rôle AD DS
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

# Création forêt ncc.local
Install-ADDSForest `
  -DomainName "ncc.local" `
  -DomainNetbiosName "NCC" `
  -ForestMode "WinThreshold" `
  -DomainMode "WinThreshold" `
  -InstallDns:$true `
  -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force) `
  -Force:$true
# Redémarrage automatique après promotion

# Pool DHCP pour VLAN USERS
Add-DhcpServerv4Scope -Name "USERS-VLAN40" `
  -StartRange 10.10.40.100 -EndRange 10.10.40.200 -SubnetMask 255.255.255.0
Set-DhcpServerv4OptionValue -ScopeId 10.10.40.0 `
  -Router 10.10.40.1 -DnsServer 10.10.10.10 -DnsDomain ncc.local

AD-DC02 — Contrôleur secondaire & DHCP Failover

PowerShell — AD-DC02 (10.10.20.11, VLAN SERVERS)Windows Server 2022
# Promotion en DC secondaire
Install-ADDSDomainController `
  -DomainName "ncc.local" `
  -Credential (Get-Credential NCC\Administrator) `
  -InstallDns:$true `
  -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force) `
  -Force:$true

# Validation réplication inter-DC
dcdiag /test:replications
# → passed ✓

# DHCP Failover Hot Standby (bascule automatique 60s)
Add-DhcpServerv4Failover `
  -Name "NCC-Failover" -PartnerServer "AD-DC02.ncc.local" `
  -ScopeId 10.10.40.0 -Mode HotStandby `
  -AutoStateTransition $true -MaxClientLeadTime 00:01:00

WEB-FRONT — Nginx Reverse Proxy + TLS (DMZ)

Ubuntu 22.04 — WEB-FRONT (10.10.30.10)Linux
# Installation Nginx
sudo apt install -y nginx

# Certificat TLS auto-signé
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/ssl/private/ncc-selfsigned.key \
  -out /etc/ssl/certs/ncc-selfsigned.crt \
  -subj "/C=FR/ST=IDF/L=Saint-Denis/O=NCC/CN=ncc.local"

# Virtual host Nginx — /etc/nginx/sites-available/ncc
server {
    listen 80;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl;
    ssl_certificate     /etc/ssl/certs/ncc-selfsigned.crt;
    ssl_certificate_key /etc/ssl/private/ncc-selfsigned.key;
    location / {
        proxy_pass http://10.10.20.30:8080;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    location /monitoring {
        proxy_pass http://10.10.20.40/zabbix;
    }
}
sudo ln -s /etc/nginx/sites-available/ncc /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
